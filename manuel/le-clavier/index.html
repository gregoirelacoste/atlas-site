Le clavier

Espace ouvre la boîte : une lettre choisit une famille, la suivante agit. Voici les commandes, les gestes directs et les raisons d'un refus.

Espace ouvre la boîte : une lettre choisit une famille, la suivante agit. Voici les commandes, les gestes directs et les raisons d’un refus.

La touche maîtresse

Espace ouvre une boîte au-dessus de la barre Git : préfixe tapé, titre, puis lettres disponibles.

La boîte liste les familles de commandes. Une lettre en choisit une ; la suivante agit et ferme la boîte.

Trois frappes, sans délai : la touche maîtresse, le module ou panneau, le geste.

Lettre Module ou commandes
f Fichiers
a Arbre
c Détail : Code ou Passage
s recherche
g Git
r recette
t Ticket : Statistiques, Journal, Ticket, Parcours
k Contrats
h pages
← ↑ → ↓ panneau gauche, centre, droite, bas
0 restaurer Fichiers / Ensemble / Code / Git

Les familles ciblent une vue ou un geste, pas une place obligatoire dans l’écran. Voir les panneaux et les modules.

Les familles, geste par geste

La boîte affiche les options du module ou du panneau désigné.

Choisir un panneau

Accord Geste Ce qu’il fait
Espace ← f Fichiers à gauche installe le module dans le panneau désigné
Espace ↑ a Arbre au centre installe Arbre en conservant son mode
Espace → a Arbre à droite déplace le même Arbre
Espace ↓ g Git en bas installe Git dans le panneau inférieur

Agrandir et restaurer

Accord Geste
Espace ← ← agrandir / restaurer le panneau gauche
Espace ↑ ↑ agrandir / restaurer le centre
Espace → → agrandir / restaurer le panneau droit
Espace ↓ ↓ agrandir / restaurer le bas
Espace + flèche + 0 cacher / révéler le panneau désigné, en conservant sa lecture et sa barre de commandes
Échap restaurer le panneau agrandi
Espace 0 disposition initiale

Le détail du rendu unifié et côte à côte est dans Le Code.

Les commandes dépendent des modules installés

Lettre Geste
f Fichiers
t Ticket et ses quatre sous-vues
k Contrats

La première lettre ouvre les options du module, à condition qu’il occupe un panneau. Détail rangé, c disparaît du premier niveau ; il reste proposé après une flèche pour l’installer. Aucune lettre répétée ne masque un module. Les vues se lisent ensemble dans des panneaux distincts. Inventaire n’est plus proposé dans les sélecteurs. Les vues sont décrites dans Relire et endosser, Fichiers et Inventaire et Ticket, fils et Journal.

Espace a — Arbre

Lettre Geste
f Arbre par flux
e vue d’ensemble
n favoris seuls ⇄ vue entière
p tout plier ⇄ déplier

Flux et Ensemble sont deux modes du même module. Espace a e choisit Ensemble, Espace a f choisit Flux. Fichiers est un module indépendant : il n’est pas un mode d’Arbre. Contrats est un module distinct, sous k. Voir L’Arbre, La vue d’ensemble et Ce qui dépend de quoi.

Espace c — Code

Lettre Geste
p tout plier ⇄ déplier
s unifié ⇄ côte à côte

Espace c s choisit le rendu unifié ou côte à côte. Le plein écran se demande séparément, par deux mêmes flèches : changer de rendu ne retire aucun module de l’affichage. À l’entrée en plein écran, Code choisit le côte à côte et déplie le fichier entier. Restaurer retrouve le rendu et les plis compacts ; ce rendu automatique n’écrase pas ta préférence.

Le pli concerne tous les blocs du Code, enfants compris. Il se refuse sans lecture visible ou en recette.

Espace t — Ticket

Lettre Sous-vue
s Statistiques de relecture
j Journal
t Ticket et critères
p Parcours

Les quatre boutons du module offrent les mêmes choix. Déplacer Ticket conserve la sous-vue choisie. Les quatre vues partagent un seul emplacement. Statistiques rassemble les comptes de relecture, la répartition du diff et les angles morts.

Espace s — recherche

Lettre Geste Ce qu’il ouvre
f un fichier par son nom une fenêtre où tu tapes un nom : la liste des fichiers du chapeau se filtre à la frappe, Entrée ouvre le fichier dans le Code
g grep dans les fichiers une fenêtre où tu tapes une chaîne : Atlas la cherche dans le contenu des fichiers, Entrée ouvre la ligne trouvée
d usages d’un nom sa définition puis ses usages, par nom

Un texte sélectionné au moment où tu presses Espace devient la saisie.

Le chapeau, c’est le dossier qui héberge tes repos : les deux recherches couvrent tous ses repos, pas seulement ceux que la feature touche.

Les options f, g et d ouvrent une fenêtre modale par-dessus l’écran, avec un aperçu du code à droite de la liste ; elles ne portent donc jamais le ● de « déjà à l’écran » — une recherche n’a pas d’état à montrer, et la refermer oublie tout, y compris la base de comparaison que la fenêtre des fichiers te laisse choisir. Ce que chacune trouve, son plafond et son aperçu sont dans Fichiers et Inventaire ; le clavier qui vit dans ces fenêtres est plus bas, sur cette page.

Espace g — Git

Lettre Geste
l Local
b Branches & repos
r Revue

Ces lettres choisissent un mode dans le module Git installé, quel que soit son panneau. Les rejouer conserve le mode ; aucune ne ferme la vue. Les trois modes sont dans Le panneau Git.

Espace r — recette

Lettre Geste
a Protocole
t Critères
n Non-régression
c Captures

Installer Recette (Espace ← r, par exemple) fournit sa lecture d’exécution à Arbre, Fichiers et Détail. La remplacer rend le Code ; cacher son panneau conserve ce pouvoir. Ses options sous r apparaissent dans l’aide. Détail affiche les événements ou médias du nœud sélectionné. Voir La recette.

Espace h — pages

Lettre Geste
t Tableau
c Config
h Harnais

Ces gestes cliquent les boutons du header. Voir Le Tableau, Configurer un projet et La page Harnais.

Cacher un panneau, conserver sa lecture

Espace, flèche, 0 cache ou révèle le panneau désigné, avec sa lecture et sa barre de commandes. Un plein écran retire temporairement les autres panneaux : leurs lectures restent présentes, mais aucun endossement ne part sur le Code invisible. Échap ou deux mêmes flèches restaurent la visibilité précédente, avec les tailles et les lectures. Un module rangé se réinstalle explicitement : Espace, flèche du panneau, lettre du module.

Ce qui reste direct

Ce qu’on répète trente fois par séance ne paie pas une boîte. Ces gestes partent sans préfixe, et la boîte les rappelle en pied de sa première liste :

Touche Ce qu’elle fait
0 endosser — relu, non jugé
1 – 4 endosser en notant la criticité
? je n’ai pas compris
f favori ⇄ — le nœud ouvert
+ / - révéler plus / moins — le pointeur sur la vue d’ensemble
↑ ↓ ← → se déplacer, plier, déplier ; en vue d’ensemble, de boîte en boîte
Alt+← / Alt+→ vue précédente / suivante de l’historique
Alt+↑ / Alt+↓ faire défiler le Code sans quitter l’Arbre
Backspace revenir
Échap dépiler le dernier geste

Les trois premiers sont le geste de relecture — endosser, c’est dire « j’ai lu cette ligne et je la prends à mon compte » : leur sens exact, ce qu’ils écrivent et ce qu’ils retirent sont dans Relire et endosser. Ils visent le nœud ouvert : sans lui, rien. Alt+← et Alt+→ parcourent l’historique des vues consultées (Le Code) ; Alt+↑ et Alt+↓ font défiler le Code sans bouger la sélection : la flèche seule pilote l’Arbre, Alt + flèche le Code.

Échap dépile le dernier geste qui a pris de la place, du plus récent au plus ancien — les occurrences allumées dans le Code, les appelants allumés, la loupe d’inventaire, la loupe de repo, la loupe d’impact, le tiroir d’impact, le flux isolé (un flux est un itinéraire d’appel, du point d’entrée jusqu’au bout), le côte à côte, puis, hors mode recette, le Code ouvert — le nœud tombe avec. Sinon, rien.

Ce que la boîte dit d’elle-même

Trois marques, et elles portent des faits, pas des suggestions :

Marque Ce qu’elle dit
● en bout de ligne ce geste est déjà à l’écran — Ticket est sur cette sous-vue, Arbre est déjà en Flux ou Ensemble, la page est ouverte
une lettre atténuée, une raison sous elle elle ne peut rien faire ici, et la raison est écrite en clair
une ligne rouge sous la liste ta dernière frappe n’a rien donné, et la boîte reste ouverte

En pied, la boîte rappelle Échap ferme.

Les raisons de griser une lettre

Une lettre grise dit toujours pourquoi :

Raison affichée Quand
pas sur une page une page — Tableau, Harnais, Config — occupe l’écran : seule la famille h agit
sans feature aucune feature n’est ouverte : ce qui pilote une carte attend (section suivante)
sans carte aucune carte n’est chargée — les gestes de l’Arbre n’ont rien à viser
rien d’ouvert à droite — ouvre un nœud le côte à côte, quand le Code n’a rien d’ouvert
rien d’ouvert à droite tout plier dans le Code, quand aucun code n’est affiché
en mode recette les vues du volet de code, la vue d’ensemble et tout plier dans le Code, pendant la recette
en mode code les vues Recette, Non-régression et Captures, hors du mode recette
rien à dessiner la vue d’ensemble, sur une feature qui ne touche aucun symbole qu’elle montre (l’Arbre dit pourquoi)
en vue d’ensemble tout plier, pendant que la vue d’ensemble cache l’Arbre
sans feature le module Contrats n’a pas de carte à présenter
aucun nom à chercher ni nom sélectionné, ni symbole survolé, ni symbole affiché dans le Code

Taper une lettre grisée ne ferme pas la boîte. Elle répète la raison ; tape une autre lettre ou Échap.

Quand aucune feature n’est ouverte

Atlas est alors en mode local (Prise en main) : l’accueil au centre, qui affiche lui-même les sept colonnes, et le projet tel qu’il est sur le disque. Espace ouvre la boîte comme partout.

Ce qui lit le disque marche : Fichiers installé, les trois recherches s f, s g, s d, le côte à côte c s d’un fichier ouvert, Git (g) et les pages (h). Ce qui pilote une carte dit sans feature — Arbre, les autres modules de lecture, Recette ; leur raison est dite en clair. Les gestes de relecture n’ont aucune ligne à viser.

Se tromper, fermer, laisser passer

Ce que tu tapes Ce qui se passe
une lettre inconnue la boîte le dit — rien sous « Espace c » : x — et attend
Shift+ ou Alt+ avec une lettre jamais un accord : la boîte l’affiche telle quelle dans sa ligne rouge
Ctrl ou ⌘ avec n’importe quoi la touche appartient au navigateur : Atlas la laisse passer, la boîte reste ouverte
Espace à nouveau la boîte se ferme
Échap la boîte se ferme — et c’est elle qui l’a, pas le panneau Git ni la page
un clic n’importe où la boîte se ferme, comme un menu

Si un dialogue s’ouvre tout seul pendant que la boîte est là — une mise à jour disponible, une proposition de partage —, la boîte se referme et la touche part au dialogue. Aucun accord n’agit derrière un voile.

Là où le clavier ne part pas

C’est la contrepartie d’une touche unique : une seule garde, posée sur la touche maîtresse, dont tout le reste hérite.

  • Dans un champ de saisie — zone de texte, liste déroulante, texte éditable —, rien ne part. Espace y écrit un espace, 0 y écrit un zéro. La page Config, pleine de champs, en dépend.

  • Depuis chaque panneau, y compris un bouton ou un lien focalisé, Espace ouvre l’aide. Changer le panneau actif ne la désactive pas. Dans les champs de texte, les touches restent celles de la saisie ; une boîte de dialogue ouverte garde également son interaction.

  • Derrière une fenêtre modale, rien ne part : ni la boîte, ni un geste direct. Les deux fenêtres de recherche en sont : tant que l’une est ouverte, 0 n’endosse rien et Espace n’ouvre pas la boîte — il écrit un espace dans le champ, qui a le focus dès l’ouverture.

  • Pendant qu’une page occupe l’écran (Tableau, Harnais, Config), la boîte s’ouvre encore — elle y dit ce qui est vivant et pourquoi le reste ne l’est pas —, mais aucun geste direct n’agit. 0, en particulier, écrirait un endossement sur un nœud que l’écran ne montre plus. Échap referme la page et revient à la carte.

Sur un AZERTY, et sur un clavier sans lettre latine

Une lettre est un mnémonique : a pour Arbre, g pour Git. C’est donc ce qui est écrit sur la touche qui compte, pas où elle se trouve. Sur un AZERTY, a est bien la touche marquée a.

Les chiffres, eux, se lisent à la position. Sur un AZERTY, la rangée du haut ne produit pas de chiffres sans Shift — et c’est justement pour ça : la touche marquée 0, qui produit à, endosse quand même, et celles marquées 1 à 4 notent la criticité, avec ou sans Shift. Le pavé numérique marche aussi.

Le ? se lit au caractère, parce qu’il n’a pas de place commune d’un clavier à l’autre : tape un point d’interrogation, quelle que soit la combinaison qui le produit chez toi.

Enfin, sur un clavier qui ne produit aucune lettre latine — cyrillique, grec —, Atlas retombe sur la position physique de la touche : les lettres redeviennent celles d’un QWERTY.

Ce qu’Atlas ne fait pas

  • Il ne laisse pas redéfinir une touche. Il n’y a aucun réglage de clavier, ni dans Config, ni dans un fichier du projet. La table est celle de cette page, partout, pour tout le monde.
  • Il n’attend jamais. Aucun délai entre deux frappes : rien ne part ni ne se perd selon ta vitesse.
  • Il ne prend aucun raccourci clavier à Ctrl ou ⌘. Ces touches-là restent au navigateur et à ton système ; la seule chose qu’Atlas en lit, c’est Ctrl/⌘ maintenue, qui allume les liens du Code pour le clic suivant. Le seul modificateur qui déclenche un geste est Alt, pour la navigation par diff.
  • Il n’agit jamais hors de ce que tu vois. Pas d’accord derrière un dialogue, pas d’endossement derrière une page, pas de raccourci depuis un champ de saisie.
  • Il n’enregistre pas tes gestes. Ce qui se retient d’une session à l’autre, c’est l’état de l’écran — la vue ouverte, les colonnes repliées, les plis de l’Arbre —, jamais la suite de touches qui l’a produit.

Limites connues

  • La boîte ne se cherche pas. Il n’y a ni filtre, ni recherche par mot : on l’ouvre et on lit. Sur les colonnes à cinq ou six lettres, c’est une liste à parcourir des yeux.
  • Le premier niveau dépend des modules installés. Les panneaux, la recherche et les pages restent proposés. Dans un groupe, chaque option refusée dit sa raison.
  • Les gestes rappelés en pied ne sont là qu’au premier niveau. Dans une colonne, la boîte ne montre que ses lettres.
  • Tab n’a rien d’un accord. Dans le panneau Git il change de mode, dans la fenêtre des fichiers il fait tourner la base de comparaison, ailleurs il déplace le focus du navigateur.
